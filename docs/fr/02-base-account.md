# 02 — Base Account et permissions

Base Account regroupe connexion, sous-comptes et transactions groupées.
Sign in with Base authentifie une session mais n’autorise pas automatiquement toute dépense.
Les spend permissions bornent actif, montant, cadence et bénéficiaire autorisés.
Un agent doit recevoir la capacité minimale nécessaire à sa tâche.
L’interface doit distinguer création de permission et paiement immédiat.
La révocation et l’expiration font partie du flux normal, pas d’un cas exceptionnel.
Les paymasters peuvent sponsoriser le gaz sans supprimer les risques de l’appel exécuté.
Chaque permission persistante doit être visible et réexaminable par l’utilisateur.
